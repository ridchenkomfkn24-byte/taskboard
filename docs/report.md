# Звіт з Лабораторної роботи №4

1. **Що змінилося у виводі git status після git add?**
   Файли перейшли зі стану Untracked/Modified до стану "Changes to be committed" (додані в індекс).

2. **Що показує git diff?**
   Показує різницю між поточними змінами у файлах та останнім збереженим станом (рядок з + відповідає доданому вмісту, з - — видаленому).

3. **Чим відрізняється git switch main від git merge?**
   `git switch main` перемикає робоче середовище на гілку main, а `git merge` об'єднує зміни з іншої гілки в поточну.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через одночасне редагування одного й того самого рядка в index.html у двох різних гілках. Я розв'язав його вручну, відредагувавши файл, видаливши службові позначки Git та зробивши merge-коміт.

## W-07: Семантична розмітка та сторінка «Про автора»

Семантична розмітка визначає чітку структуру веб-документа для браузера, пошукових систем і засобів доступності. На відміну від універсального тегу `<div>`, який не має власного смислового значення, семантичні теги описують ролі та призначення конкретних блоків сторінки. Це покращує читабельність коду, спрощує його подальшу підтримку та позитивно впливає на SEO.

Використані семантичні теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<footer>`.

## W-10. Flexbox, адаптивність і форма

### Відповіді на запитання:
1. **Навіщо потрібен `flex-wrap` та медіа-запит?**
   - `flex-wrap: wrap` дозволяє flex-елементам автоматично переноситися на наступний рядок, якщо їм не вистачає місця в контейнері.
   - Медіа-запити (`@media`) дозволяють змінювати CSS-стилі сторінки під різні розміри екранів (наприклад, на мобільних пристроях шириною до 600px елементи форми вибудовуються у вертикальну колонку).

2. **Навіщо у полів атрибути `name` та `id`?**
   - `name` вказує назву параметра, за якою сервер (наприклад, Flask) отримує значення з форми під час HTTP-запиту.
   - `id` надає елементу унікальний ідентифікатор усередині HTML-документа, необхідний для роботи JavaScript та зв'язування з тегом `<label>` через атрибут `for`.
